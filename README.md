# Capi la Tortue — site (FR + EN)

Site statique (GitHub Pages), sans dépendance : il se déplace tel quel vers un autre hébergeur.
Généré par `build_site.py` (sources gardées hors du dépôt).

- Français à la racine : `index.html` · `jeu/` (installable, hors-ligne) · `villes/` 14 pages · `coloriages/` · `cahier/` · `maternelle/`
- Anglais sous `en/` (angle « Learn French with Capi ») : `en/` · `en/game/` · `en/towns/` · `en/coloring-pages/` · `en/activity-book/` · `en/teachers/`
- Chaque page a son équivalent dans l'autre langue (bouton FR/EN, balises hreflang, sitemap).
- Liens d'achat : `BUY_URL`, `BUY_URL_EN` et `AMAZON_URL` dans `site_data.py`.
- Mesure d'audience : GoatCounter (`capilatortue.goatcounter.com`).
